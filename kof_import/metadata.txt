description=Import KOF survey files (the Norwegian coordinate file format) as points, lines and polygons.
about=KOF is the coordinate file format used by Norwegian surveying instruments and software (Norkart KOF specification 2.00). The plugin reads points (05 records), lines and polygons (09 blocks) and the file header, detects the coordinate reference system (EUREF89 UTM and NTM, NGO1948, ED50, WGS84 UTM and more) and checks the axis order. Repeated measurements of the same point can be merged into mean points with standard deviations. Use it from Vector > KOF Import, the Processing toolbox, or by dragging a .kof file onto the map. The user interface is available in English and Norwegian.

    - CRS recognised from ArcGIS export text and SRID/EPSG comments
    - Axis order is checked and corrected when the file states it wrongly
    - Points with missing north or east are reported instead of misread
